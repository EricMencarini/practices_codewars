# Codewars Practice – Python & SQL

This repository contains solutions for Python, SQL, Scala, Shell, Java exercises based on the free challenges from [Codewars](https://www.codewars.com/).

## 📁 Structure

- **python/** – Python exercises organized by difficulty
- **sql/** – SQL exercises organized by difficulty
- **scala** - Scala exercises organized by difficulty
- **shell** - Scala exercises organized by difficulty 
- **java** - Scala exercises organized by difficulty
- **readme.md** – This documentation file

## 🚀 Purpose

The main goal of this repository is to **practice and improve problem-solving skills** in SQL and Python at first but also start to learning
Scala, Shell and just by curiosity Java.
.  
It is intended to help reinforce programming logic, data manipulation, and algorithmic thinking for **data engineering and general programming**.  
This repository also encourages exploring **different approaches for each problem** to deepen understanding.

## 🐍 Python Topics

- Lists, dictionaries, and sets  
- Functions and recursion  
- List comprehensions  
- String and number manipulation  
- Mathematical operations and algorithms  
- Problem-solving patterns for data engineering

## 🛢️ SQL Topics

- Aggregations and grouping  
- Subqueries and CTEs  
- Window functions  
- Data transformations and filtering  
- Query optimization techniques

## 🔷 Scala Topics (fundamentals)

- Basic syntax and type system
- val vs var and immutability
- Control flow (if, for, match)
- Core collections (List, Seq, Map, Set)  
- Functions and basic functional operations (map, filter)


## 🐚 Shell / Bash Topics (fundamentals)

- Essential commands (ls, cd, cp, mv, rm)
- Pipes and redirection (|, >, >>)
- Variables and environment variables 
- Basic shell scripting and execution
- File and text manipulation (grep, awk, sed)

## ☕ Java Topics (Basics)

- Basic syntax and class structure
- Primitive types and variables
- Control flow (if, for, while)  
- OOP fundamentals (classes, inheritance, encapsulation) 
- Core collections (List, Set, Map)
